# Guardines-del-bosque
El bosque esta perdiendo sus arboles y animales debido a la contaminación. El jugador debe convertirse en un guardián que recorre diferentes zonas para limpiar el ambiente, plantar arboles y rescatar animales 
# Fase 1 Análisis 
El juego se trata de un jugador que salva el bosque contaminado 
# Fase 2 Diagrama de flujo
El jugador tiene solo 3 vidas y cada nivel que gane se le da premio vidas, objetos y mejoras
